# Vibe Coding 实现功能技巧（省 Token）

Vibe Coding 做一个项目要实现一个功能时：

- 记得先切换至 Ask 模式，把功能需求详细描述给 AI，让它给出这个功能的具体实现方案
- AI 给出这个功能的具体实现方案后，我们需仔细 review 一下这个方案是否 OK，是否符合我们的预期，有些地方不满意则调整
- 然后再切换到 Agent 模式，让 AI 根据方案实现功能

这样做的好处是：

- 既能提高功能实现的准确率，又能避免 AI 乱做（做出来的效果不符合我们的预期），比直接开 Agent 模式让 AI 盲搞省很多 Tokens
- 让 AI 盲搞，一轮一轮对话调整，很费时间、费精力、费 Tokens
