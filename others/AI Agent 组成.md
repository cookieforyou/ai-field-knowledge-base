## 一、AI Agent 组成

业界公认，一个完整的 AI Agent 由以下四个部分组成：

Agent = LLM（大脑）+ Planning（规划）+ Memory（记忆）+ Tools（工具）

## 二、拆解 Agent 的四大核心组件

### 2.1、大脑 (LLM - 大语言模型)

### 2.2、规划 (Planning)

核心机制：ReAct 框架（Reasoning + Acting）

目前 Agent 最经典的思考模式，分为三步循环：

当你布置一个复杂任务（比如 “帮我策划一场 50 人的公司团建”），Agent 不会一上来就瞎写，而是会拆解任务。

- Thought（思考）：我需要先确定预算，然后查场地，最后安排餐饮。
- Action（行动）：调用 “计算器工具” 算预算，调用 “搜索工具” 查场地。
- Observation（观察）：哦，搜索结果显示 A 场地太贵了，我得换 B 场地。

循环以上步骤，直到任务完成

### 2.3、记忆 (Memory)

没有记忆的 Agent 就像金鱼，聊完就忘。

短期记忆（Short-term Memory）：就是当前对话的 “上下文窗口”，它记得你上一句说了什么。

长期记忆（Long-term Memory）：知识点：向量数据库 (Vector DB) 与 RAG 技术。比喻：就像给 Agent 配了一个带索引的超级档案柜。你把公司的《员工手册》、《产品说明书》撕碎成一条条知识点存进去。当你问问题时，Agent 会去档案柜里精准检索出相关的段落，再结合自己的大脑回答你。这就解决了 AI “胡说八道（幻觉）” 的问题。

### 2.4、工具 (Tools)

让 Agent 真正 “长出手脚” 的关键。知识点：Function Calling（函数调用）

大模型本身是不懂执行代码的，但它会 “开条子”。比如它需要查天气，它会输出一张结构化的 “条子”（JSON 格式）：`{"工具": "天气查询", "参数": {"城市": "北京"}}`。你的系统拿到这张条子，去调用真实的天气 API，再把结果喂回给大模型。

2026 最新趋势：MCP 协议 (Model Context Protocol)

由 Anthropic 提出的统一标准，相当于给 Agent world 发明了 “USB-C 接口”。以前接一个工具要写一套代码，现在只要支持 MCP，Agent 就能即插即用各种本地文件和外部服务。
